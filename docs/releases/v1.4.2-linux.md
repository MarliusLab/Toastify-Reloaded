# Linux 1.4.2 — Lyrics Plus, two-press toast shortcut and update parity

Toast title, artist, artwork/background clicks and Enter/Space request Lyrics Plus through the fixed `spotify:app:lyrics-plus` page. The configured Show Toast shortcut first shows a toast and, while a toast is visible, requests Lyrics Plus. It returns to showing a toast after expiration. Existing settings remain in their original folder; the new shortcut setting is additive and existing assignments are preserved.

Added progress, byte counts and cancellation for package downloads; bounded version probes, repair processes and stalled HTTP bodies; strict size/SHA-256 verification; and independent startup probes/polling. An updater restart does not immediately repeat an automatic install. Existing MPRIS controls, themes, X11/Wayland integration, import/export and Spicetify repair remain available.

Velopack AppImages and architecture-specific package feeds are now available for x64 and ARM64. This release establishes their first full baseline; future compatible releases can supply deltas, with full fallback when a usable cached base is absent. DEB installations retain the package-manager path and tar installations retain their manual-update behavior; they are not silently converted into AppImages. No old settings are replaced.

Lyrics Plus must already be enabled/applied; lyrics availability depends on its providers. Native X11/Wayland shortcut availability remains subject to desktop permissions and collisions. No synthetic global input bypass is introduced. All three platform builds must pass at the release source before publication. Existing tags remain unchanged.
