# Windows 1.3.8 — open Spotify from the toast

Click the toast, including its title, artist or artwork, to bring Spotify to the foreground. Minimized Spotify windows are restored. If Spotify is closed, Toastify uses its registered `spotify:` protocol. Ctrl+drag still moves the toast; Enter or Space also activates a focused title or artist.

The Windows media-session API supplies title, artist and timeline but does not supply a Spotify catalog track URI. In that case the toast activates Spotify without guessing a track from text. The opener also supports validated catalog URIs when a trusted identifier is available, with a canonical HTTPS fallback. Invalid identifiers cannot open arbitrary links.

Repeated clicks are serialized, pending activation is canceled when the toast closes, and launch failures allow retry with a localized tooltip. Existing settings, appearance, animations, playback controls and the 1.3.7 maintenance fixes are preserved.

Packages: `ToastifyReloaded-Setup-win-x64.exe`, `ToastifyReloaded-Setup-win-arm64.exe`, and `SHA256SUMS-Windows.txt`.

Install this version to receive the click handler; an older running executable retains its older behavior.
