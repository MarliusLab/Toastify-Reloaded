# Windows 1.3.6

Fixes update discovery for legacy release tags such as `v.1.3.5`, alongside canonical tags such as `v1.3.6`. The updater uses the current MarliusLab repository address. Existing settings, hotkeys, themes and Spotify integration are preserved.

Packages: `ToastifyReloaded-Setup-win-x64.exe` and `ToastifyReloaded-Setup-win-arm64.exe`, with `SHA256SUMS-Windows.txt`.

The release pipeline verifies the version and regression tests, builds both installers, and publishes these files only after the main Windows build succeeds. This release does not add the Linux/macOS toast-link implementation to Windows.
