# Windows 1.3.9 — go to the currently playing song

Click the toast to open/restore Spotify and request its **Go to Now Playing** command (`Alt+Shift+J`). You can also press **Alt+Shift+J while a toast is visible**, including when the toast does not have keyboard focus. Enter/Space on either toast text line uses the same action. Ctrl+drag still moves the toast.

This targets the item currently playing in Spotify when the action runs. It does not request play, pause, skip or seek, and does not open a track URI that could select a different recording. The Windows SMTC backend still has no catalog track URI; this command uses Spotify's documented desktop navigation shortcut instead.

Toastify verifies Spotify's foreground window before sending the shortcut, waits briefly for held keys to be released, and reports blocked navigation separately from successful app activation. Its temporary shortcut is suspended while forwarding the command to avoid intercepting itself. Overlapping toasts share one registration; closing the last toast releases it. Existing global-hotkey preferences and saved settings are preserved.

If another app owns the shortcut, click or Enter/Space still activates Spotify, but Toastify does not forward the occupied combination. Native input may be blocked by Windows or unsupported by the Spotify client; accepted input does not itself prove that Spotify navigated. No playback API or media transport command is sent by this action.

Packages: `ToastifyReloaded-Setup-win-x64.exe`, `ToastifyReloaded-Setup-win-arm64.exe`, and `SHA256SUMS-Windows.txt`.
