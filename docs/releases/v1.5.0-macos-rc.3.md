# macOS 1.5.0 RC3 — Lyrics Plus and update parity

Toast title, artist, artwork/background clicks and Enter/Space request Lyrics Plus through the fixed custom-app page. The configured Show Toast shortcut first shows a toast and then opens Lyrics Plus while a toast remains visible. Alt+Shift+J retains a separate guarded Now Playing action. Existing settings are preserved, and the new Show Toast field is added with a compatible default.

Added independent Spotify/Spicetify version probes, early media polling, bounded repair processes, download progress/cancellation and strict package size/SHA-256 verification. Fixed quoting, process-wait limits and rollback behavior in the legacy app-replacement helper. Updater restarts cannot immediately repeat an automatic install; saved preferences are unchanged.

ZIP/DMG bundles now contain the Velopack updater and architecture-specific package feeds for Intel/Apple Silicon. RC3 is the first full macOS package baseline; future releases can supply deltas with full fallback. Existing bundle identifier, settings locations, Automation description, startup integration and package formats are retained. macOS remains a release candidate: ad-hoc CI signatures do not establish Developer ID/notarization or interactive Spotify/Accessibility acceptance.

Lyrics Plus must already be enabled/applied and providers may not supply lyrics for every song. Global shortcuts and native Now Playing require the normal macOS permissions. All three platform builds must pass at the same source before publication. Existing tags remain unchanged.
