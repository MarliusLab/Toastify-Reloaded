# macOS 1.5.0 RC2 — prerelease

Adds clickable title and artist links to the displayed Spotify track. AppleScript captures the catalog identifier with the metadata and checks it did not change during the read. The opener tries Spotify, then the canonical HTTPS track page, then app activation. Unsupported or missing IDs only activate Spotify.

Fixes the obsolete Preview 1 self-test assertion, stale version labels and DMG image-capacity failures. Timeouts stop only launcher helpers, progress continues during opening, and temporary missing IDs do not duplicate notifications. Existing settings and installation identifiers are preserved.

Packages: Intel and Apple Silicon ZIP/DMG, with `SHA256SUMS-macOS.txt`.

**This remains a release candidate.** CI validates both architectures, signatures, packages and native Apple Silicon startup. Real Spotify Automation/Accessibility permissions, Intel execution, desktop behavior, Spicetify/updater integration and Gatekeeper acceptance remain to be tested. Developer ID signing and notarization are optional; when credentials are absent the packages use ad-hoc signatures and are not notarized.
