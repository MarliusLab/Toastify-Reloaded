# Windows 1.3.10 — transition to Velopack updates

This is the one-time transition from the NSIS updater to Velopack. Install the matching `ToastifyReloaded-Setup-win-x64.exe` or `ToastifyReloaded-Setup-win-arm64.exe`, or accept the update from the existing application. The bridge retains the existing installation directory and installs the supported per-machine Velopack/MSI layout there. Program Files installations can still require Windows elevation.

Existing settings remain in `%APPDATA%\ToastifyReloaded\settings.json`. Themes, hotkeys, Spotify/Spicetify maintenance, minimized startup, toast links and Alt+Shift+J are preserved. Existing enabled startup entries use the stable root launcher; a disabled startup preference stays disabled.

After migration, updates use architecture-specific Velopack feeds and packages. The updater downloads available deltas, reconstructs and verifies the complete package, then hands off to the updater and restarts Toastify. A missing or unusable delta falls back to a full package. Progress and cancellation remain visible during download/preparation.

The first bridge is a full, larger download: it includes both the MSI and a verified full-package base for the user's update cache. There is no previous public Velopack release, so this release publishes the first full baseline, not a fictitious delta from the legacy installer. Future releases can generate deltas against this baseline. Synthetic delta reconstruction/fallback tests are separate from live user migration acceptance.

The old NSIS uninstall registration is retired only after successful migration; MSI handles subsequent uninstall. Installer tests use isolated/fake system operations. An actual elevated installation and subsequent update on a real Windows machine still require acceptance testing. The pinned stable Velopack updater's recovery behavior is not a guarantee of complete rollback after every filesystem failure.

Release assets include the two compatibility Setup executables, two per-machine MSI packages, two full `.nupkg` baselines, per-architecture JSON/RELEASES feeds and `SHA256SUMS-Windows.txt`. Existing tags and Linux/macOS releases are preserved.
