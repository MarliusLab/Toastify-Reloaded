# Linux 1.4.3 — distinguish installed updates from restart failures

After a legacy AppImage replacement or successful DEB transaction, a failed restart no longer reports that installation failed or offers to repeat the same update. The result identifies the installed package and provides manual restart guidance. Failures before installation remain failures, and native Velopack handoff remains explicitly separate from completed installation.

The DEB packages now explicitly depend on the GLib command-line tools required by the Show Toast and scoped current-track shortcuts. Existing settings, Lyrics Plus clicks, contextual two-press shortcut, playback controls and X11/Wayland behavior are preserved.

The next Show Toast press may be delayed for as long as a toast is visible; there is no fast double-tap deadline. Existing toast duration and the separate current-track action remain unchanged.

This release can generate genuine architecture-specific deltas from the verified 1.4.2 full baselines, with full fallback. Native patch-only and corrupt-delta probes use isolated files and never install the application. All three main platform builds must pass at the same source before publication. Existing tags/assets remain unchanged.
