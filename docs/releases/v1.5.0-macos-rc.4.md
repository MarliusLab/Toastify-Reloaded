# macOS 1.5.0 RC4 — post-install recovery and native delta verification

The legacy bundle replacement helper separates a successful replacement from cleanup and restart. A backup-cleanup failure cannot prevent startup after the new bundle has been committed; a failed normal-user launch is recorded as installed with manual-restart guidance. Pre-commit and rollback failures remain distinct. Existing settings, permissions, bundle identity, Lyrics Plus clicks and contextual toast shortcuts are preserved.

The next Show Toast press may be delayed: whenever a toast is still visible, it requests Lyrics Plus without a fast double-tap deadline. The configured toast duration and separate Alt+Shift+J destination are preserved.

Architecture-specific feeds can include genuine deltas from the verified RC3 full baselines, with full fallback. Native patch-only and corrupt-delta probes operate only on isolated files; they do not install or launch the app. macOS remains a release candidate, with interactive Spotify/permission/updater and distribution-signing acceptance still separate from native build/signature checks.

All three main platform builds must pass at the same source before publication. Existing tags/assets remain unchanged.
