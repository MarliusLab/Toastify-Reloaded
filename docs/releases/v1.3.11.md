# Windows 1.3.11 — open Lyrics Plus from a toast

Click a toast's title, artist, artwork or background to open **Lyrics Plus** in Spotify. Enter/Space on either text line also opens Lyrics Plus. **Alt+Shift+J while a toast is visible** retains the existing **Go to Now Playing** action. Ctrl+drag still moves the toast. Global shortcuts, themes, settings and Spotify/Spicetify maintenance remain available.

The saved **Show Toast** shortcut now has two steps: press it to display a toast, then press it again while a toast is visible to open Lyrics Plus. Once the toast closes, the next press displays a toast again. This follows your existing shortcut assignment; it does not replace it with a fixed combination. Tray and Test Toast commands continue to display a toast.

Toastify requests the fixed `spotify:app:lyrics-plus` custom-app page. Lyrics Plus follows the song currently selected by Spotify's player; Toastify does not navigate to an old toast's track, send play/pause/skip/seek commands, inject a navigation shortcut, repair Spicetify or restart Spotify during the click. Held trigger keys/buttons must be released before focus or protocol handoff.

Lyrics Plus must already be enabled and applied through Spicetify. If the page cannot be requested, Toastify tries to activate Spotify and reports the fallback. A successful protocol request cannot confirm that lyrics are available for every song or provider. Use the existing Lyrics Plus controls in the Reloaded tab to install/enable or repair it when needed.

Existing Velopack 1.3.10 installations can update inside Toastify using an available delta, with full-package fallback. Older NSIS installations should use the matching compatibility Setup once. Settings remain in `%APPDATA%\ToastifyReloaded\settings.json`; existing releases and tags are preserved.
