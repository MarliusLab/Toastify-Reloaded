# Windows 1.3.12 — installer fix and coordinated platform updates

Fixed a silent exit when the compatibility Setup was opened manually without optional update arguments. Missing `/RESTARTMINIMIZED` now uses its normal default; invalid options, a busy installer and an ARM64 package on an Intel/AMD PC produce visible messages. A native user-mode parser regression probe covers the real NSIS parser without installing anything.

Updater restarts cannot immediately repeat an automatic download/permission cycle during the same process session. The explicit Install action remains available and saved update preferences are unchanged. Desktop-user restart diagnostics now identify the failed stage while preserving the non-elevated restart requirement.

Lyrics Plus toast clicks and the configured Show Toast two-press action remain available; Alt+Shift+J retains the track action. Existing settings, themes, playback controls and Spotify/Spicetify maintenance are preserved. Full/delta Velopack updates remain supported.

Common toast control is now shared with Linux and macOS. All three native build workflows must pass for the same source before any platform release publishes. Linux 1.4.2 and macOS RC3 carry the corresponding feature and maintenance updates. Existing tags remain unchanged.
