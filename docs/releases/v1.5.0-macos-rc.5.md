# macOS RC5 — held modifiers and timed toast navigation

The configured Show Toast shortcut can be used after a delay while keeping Control or another modifier held. Both the native hook and dedicated Lyrics Plus service path wait for the primary key/mouse release rather than all modifiers. Normal click/Enter and Now Playing input guards remain separate; no synthetic input or playback command is added to Lyrics Plus.

A still-visible toast remains actionable during its exit animation. Accepted navigation invalidates the old fade/close generation and holds the same window until the request settles, then resumes its configured exit. Real Avalonia headless tests exercise production XAML, timers, overlapping windows, pending requests, entry interruption and explicit close.

Settings, saved assignments, duration and the RC distribution channel are preserved. Native package/delta/signature gates remain required for all three platforms at one source; interactive Spotify/permissions and stable signing acceptance remain separate. Existing tags/assets are unchanged.
